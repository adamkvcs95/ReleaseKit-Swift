# ReleaseKit-Swift

Work in progress, not ready to ship. The package includes version decision logic, Keychain-backed anonymous identity, an API client, a basic What's New sheet and changelog, and preliminary voting, comments, reports, blocking and events. A development demo app is included. These features require more end-to-end, accessibility and localization testing. App Attest and offline caching are not implemented. The [integration guide](AGENTS.md) describes the intended finished interface, not a released package.

For development, run `swift test` and build the `ReleaseKit` scheme for an iOS Simulator. See the main specification in the parent workspace for the complete scope.
